# Virtual Network Reconnaissance and Security Assessment Lab

## About
A hands-on cybersecurity project built using Kali Linux to practise network reconnaissance and basic HTTP security testing in a controlled local environment.

## Environment
- Operating System: Kali Linux
- Target: 127.0.0.1
- Service: Python HTTP server
- Port: 8000

## Tools
- Nmap
- curl
- Python 3

## Practical Tasks
- Identified an open HTTP port using Nmap.
- Detected the HTTP service version.
- Tested GET, HEAD and OPTIONS methods.
- Checked the robots.txt path.
- Recorded HTTP response headers.
- Created a security assessment report.

## Results
Test evidence is stored in the `results/` directory.
The assessment report is stored in `reports/assessment.md`.

## Security Note
All tests were conducted against a local lab service on 127.0.0.1.
No third-party systems were targeted.

## Learning Outcomes
- Network reconnaissance
- Port and service identification
- HTTP request and response analysis
- Basic security reporting
